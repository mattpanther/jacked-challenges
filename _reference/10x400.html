How It Works

  • Complete 10 sets of 10 reps per exercise, then move on.
  • Rest exactly 1 minute between successful sets.
  • If you fail (<10 reps), rest 90 seconds and Retry.
  • Fail the Retry → exercise is Over. Move to next.
  • Rest 5 minutes between exercises.

Setup Required

To run this app on GitHub Pages, you need to connect your own Firebase database.

  1. Go to the Firebase Console.
  2. Create a project and add a Web App.
  3. Copy the firebaseConfig object.
  4. Open this HTML file in a text editor.
  5. Find the MANUAL_FIREBASE_CONFIG variable and paste your config there.
  6. Save and refresh this page.
You also need to enable Authentication (Anonymous) and Firestore.
